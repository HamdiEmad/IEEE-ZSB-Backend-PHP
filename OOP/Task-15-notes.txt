(2) The final Keyword
    - When final keyword is used with a class, It makes the class can't be Inherited and when using with a function, It can't be overriden.
    - It can be used to protect the class logic from being changed or to prevent breaking the core functionality of the class.
    - Example:
        final class Laptop {

        }
        class ROV {
            final public cameraTest() {
                echo 'Camera is working now';
            }
        }


(3) Overriding Methods
    - Override a method means to rewrite the same method from a parent class in a child class but with some changes in the implementation.
    - Example:
        class Human {
            public $name;
            public function eat() {
                echo 'I am eating';
            }
        }
        class Male extend Human{
            public function getName() {
                parent::eat();
                echo 'Gebna Estanboly';
            }
        }

(4) Abstract Class vs. Interface
    - an Abstract class can have both abstract methods which is empty and non-abstract(implemented or concrete) methods whether an Interface has just abstract methods.
    - Abstract classes can have variables and constants, but Interfaces may only have constants.
    - A class can implement multiple interfaces:
        class hourlyEmployee implement Employee, Human, Male {

        }
